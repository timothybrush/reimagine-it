**reimagine-it v2.10.0 — one engine, seventeen distinct directions**

We just cut v2.10.0. This release closes the gap between what the skill *says* and what the engine *does* — and makes the seventeen design directions structurally distinct instead of seventeen remixes of one stylesheet.

Three things worth your time:

**1. The skill runs the CLI — full stop.** `/reimagine-it` is orchestration around `npx reimagine-it`, not a second engine. Hand-authoring the page when the CLI can run is now a listed failure mode. HTML in, HTML out — the PDF/PPTX/DOCX packs are host-conversion playbooks, never claimed as engine features.

**2. Auto stopped hallucinating fashion.** A flu-shot bulletin used to earn the `lookbook` direction because "flu shots" matched "shots" and a long list matched "a drop." The routing now requires real fashion vocabulary; the clinic proof case routes to `infographic`, the fashion campaign still routes to `lookbook`, and both stay at 100% source fidelity.

**3. Seventeen directions, seventeen stylesheets.** Every token used to embed the same shared CSS chrome — the same mesh, glyphs, donuts, and bands. Now each direction composes only the design primitives it actually uses, and the 3js scene gets a content-derived orbit rail + prism in the gutter instead of dashboard charts. Structural (class-set) difference between directions on the same source: **94.6%**. Every committed example regenerated byte-identically through the reproduction guard.

Also in this release: install docs now lead with two doors (the CLI, `npx skills add`) and name what this project is *not* — it is Kayforkind's Content-Derived Design CLI, not reimagineit.ai. CodeQL actions are pinned to one SHA so Dependabot cannot split them. Full notes: [CHANGELOG](https://github.com/Kayforkind/reimagine-it/blob/main/CHANGELOG.md).

Try it in one command:

```bash
npx reimagine-it --auto -i page.html -o redesign.html
```

Offline, deterministic, no API key. The source is the brief.
